# EcoMart – Sustainable E-Commerce Website

EcoMart is a fully functional, frontend-only e-commerce website for eco-friendly products. Built with HTML5, Tailwind CSS, and JavaScript, it features a modern, professional UI/UX and a smooth shopping experience. All product images use real Unsplash/Pexels URLs for a visually polished look.

## 🌱 Features
- Full-width hero section with real nature imagery
- Dynamic product grid with real product images
- Category, price, and search filters
- Product details with image gallery and eco-impact info
- Cart with live updates, quantity controls, and localStorage persistence
- Checkout with form validation and order summary
- Order success page with eco-impact message
- Responsive, accessible, and mobile-first design
- Modern color palette and typography (Poppins/Inter)
- No backend or authentication required

## 🚀 Getting Started
1. **Clone the repo:**
   ```
   git clone https://github.com/Rohan-Kancharla/Eco-firendly-website.git
   ```
2. **Open index.html** in your browser to view the site.
3. **(Optional) Deploy** to GitHub Pages or Vercel for a live demo.

## 🖼️ Image Credits
All product and hero images use free Unsplash/Pexels URLs. Replace with your own for production use.

## 🛠️ Tech Stack
- HTML5 (semantic)
- Tailwind CSS (utility-first, custom theme)
- JavaScript (ES6+)
- No backend required

## ✨ Customization
- Update `js/data.js` for your own products and images
- Edit Tailwind theme in `css/tailwind.css`
- Add or modify pages as needed
